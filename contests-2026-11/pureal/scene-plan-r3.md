## 2. 룩앤필 — "북유럽 키친 원테이크 (Nordic Kitchen One-take)"

국내 정수기 광고의 문법은 대체로 **유명인 모델, 큰 자막, 기능 아이콘, 밝은 하이키 쇼룸, 빠른 컷, CM송**입니다. R3는 그 반대로 갑니다.

1. **원테이크 제품 데모**: 제품에서 생활로 넘어가는 순간을 끊지 않습니다(P02, 8초 = Veo 1회 생성 길이).
2. **플래니메트릭 구도**: 조리대를 정면에서 평행하게 잡습니다. 수평·수직선이 화면 테두리와 평행하고, 원근 왜곡이 없습니다. 제품이 '정직하게' 보입니다.
3. **폴리 퍼스트**: 레버 '딸깍', 물이 컵에 차오르는 음높이 변화, 별 모양 틀 '톡', 밀가루 '퍽'. 음악은 작은 마림바 리듬 하나만 쓰고, 소리가 리듬을 만듭니다.

### LOOK LOCK
- **빛**: 오전 10시 북향 창의 부드러운 측광. 하이라이트를 날리지 않습니다. 제품의 흰색은 **회색 기운이 살짝 도는 흰색**으로 둡니다. 쇼룸처럼 반짝이는 흰색은 쓰지 않습니다.
- **팔레트**: 퓨어화이트(제품) · 밀가루 백 `#F4F0E8` · 연한 오크 `#C9A77C` · 세이지 그린 `#9AAA8E`(타일) · 별 쿠키 황갈 `#C98A3F`.
- **카메라**: P02 측면 트래킹 1회, P03 위에서 수직 고정. 나머지는 모두 고정입니다.

- **금지**: 제품 축소·확대 마법, 내부 부품·필터 해부도, 물이 공중을 나는 연출, 급수 연결 없이 물이 나오는 듯한 구도(제품 뒤 배관 쪽을 비우지 않음), 기능 아이콘·인포그래픽, 생성된 로고.

## 4. Google Flow 제작

### 생성 순서
1. **제품 기준 이미지 확정**: 제공 자산을 Ingredient로 넣고 Flow 이미지로 'P01 구도'를 생성합니다. 로고·레버·코크·전면 패널이 원본과 같은지 1:1로 비교합니다.
2. **P01 출수 시험(6~8초)**: 물줄기가 실제 출수구에서 나오는지, 출수 중 제품 형상이 변하지 않는지 확인합니다.
3. **P02 원테이크**: Frames to Video. 시작 프레임 = P01 키프레임, 끝 프레임 = P05의 오른쪽 부분(부모·아이가 나란히 선 구도). 이 컷이 성공하면 작품의 절반이 끝납니다.
4. P05 와이드 → P03·P04 탑뷰 → P06·P07·P08.

### 프롬프트 (영문, 앞에 공통 스타일 블록 + PRODUCT/CHARACTER LOCK)

**P02 — 원테이크 측면 트래킹 (최우선)**
