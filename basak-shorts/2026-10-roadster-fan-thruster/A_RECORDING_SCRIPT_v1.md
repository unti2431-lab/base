## 2. 98→49 조건 표기 (팩트 필수)

사용자 계획("같은 속도·마찰계수, 정지까지 총 수직하중 2배")은 방향이 맞다. 다만 **실제 값 두 가지와 전제 하나가 빠져 있다.** 98m는 50km/h, μ=0.1일 때만 성립하는 숫자라서 속도와 μ 값이 화면에 있어야 한다.

**권장 자막 (A06, 하단 작게, 편집 레이어에서 삽입)**
```
이론 계산 · 50km/h · 빙판 μ 0.1 가정 · μ 일정 · 정지까지 총 수직하중 2배 · 반응거리 제외
```

**짧은 버전 (두 줄)**
```
50km/h · μ 0.1 · 수직하중 2배 가정
반응거리 제외 이론값 · 실측 아님
```

| 전제 | 왜 필요한가 |
|---|---|
| 50km/h | 이게 없으면 98m는 재현할 수 없는 숫자다 |
| μ 0.1 | 블랙아이스는 대략 0.05~0.2로 폭이 넓다. 가정값임을 밝힌다 |
| μ 일정 | 실제 타이어는 누르는 힘이 커지면 μ가 조금 떨어진다(하중 민감도). 그래서 49m는 낙관값이다 |
| 반응거리 제외 | 운전자가 브레이크를 밟기 전까지 가는 거리는 빠져 있다 |
| 실측 아님 | 사용자 지적대로 성능 주장이 아니라 계산이다 |

**채널 규칙 충돌 확인**
- 이 자막은 한글이 있으므로 **INFO 이미지가 아니라 편집 자막**으로 넣는다(INFO에 한글이 있으면 불합격이다).
- INFO에는 장면당 수치를 하나만 둔다. A06 INFO는 금색 `49 m` 하나로 두고, `98 m`는 A02 INFO에서 이미 보여줬으니 반복하지 않는다. "98→49" 비교는 편집 자막이 맡는다.
