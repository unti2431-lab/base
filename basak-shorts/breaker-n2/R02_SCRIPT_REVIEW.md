## 0. 총평

R01은 **사실 관리가 매우 좋다.** 원안의 과장 다섯 가지("유압만으로 불가능", "초당 수십 번", "극한 압축", "폭발적 팽창", "가스 내보내는 밸브")를 출처를 들어 모두 걷어냈다. 한 번의 타격을 여섯 단계 인과로 쪼갠 표도 정확하다. 이 두 가지는 손대지 않는다.

문제는 **대본이 '어떻게'만 말하고 '왜'를 말하지 않는다는 것**이다. 제목은 《뿌레카 안에 질소를 넣는 이유》인데, 내레이션 9줄 중 '이유'에 해당하는 줄이 없다. 시청자는 작동 순서를 다 보고도 "그래서 왜 기름이 직접 안 치고 질소를 쓰는데?"라는 질문을 안고 나간다. 공학 쇼츠는 그 질문에 답하는 순간 저장·공유가 일어난다.

## 4. 제작 경로 — Google Flow 단독안

R01은 핵심 원리를 Blender로, 외관을 ImageGen/Omni로 나눠 만드는 계획이다. **Flow 단독 우선**으로 가려면 아래처럼 바꾼다. R01의 G0~G7 게이트와 검수 원칙은 그대로 쓴다.

### 원칙: 도해가 아니라 '실물 절개 모형'을 찍는다
Veo는 투명 단면 도해(유로, 체적 경계)를 반복해서 무너뜨리지만, **실제로 있을 법한 물건**은 안정적으로 만든다. 건설기계 제조사가 전시회에 내는 **절개 전시 모형(cutaway display model)**처럼 찍는다. 절단면은 빨갛게 칠하고 내부 부품은 실제 금속으로 보이게 한다.
- 질소·오일 색은 CLEAN에 넣지 않는다. **INFO 패스에서 공간 결합 그래픽으로 얹는다**(청록 = 질소 체적, 호박 = 오일 경로. R01 §5 색 규칙 유지).
- 질소실 체적 변화는 CLEAN에서 피스톤 위치로만 성립시킨다. 청록 영역은 INFO에서 피스톤 상단에 맞춰 그린다.

### 상태 키프레임은 순차 생성 (병렬 금지)
1. **K03**(절개 모형, 피스톤 하단 위치)을 확정한다 → 이것이 이후 모든 단면 컷의 기준 이미지가 된다
2. K03을 참조로 첨부해 **K04**(피스톤 상사점, 질소실 최소)를 만든다. 바꾸는 건 피스톤 위치 하나뿐이다
3. K04를 참조로 첨부해 **K06**(하강 중간)을 만든다
4. K06을 참조로 첨부해 **K07**(정 상단과 2~3mm 틈, 접촉 직전)을 만든다
5. 영상: Frames to Video로 **K03→K04**(상승), **K04→K07**(하강)을 만든다. 시작·끝 프레임을 모두 지정해서 피스톤 위치를 통제한다

### 접촉 장면은 '액션 컷'으로 처리
Veo에서 '정확히 닿는 순간'은 관통·합체가 가장 잘 일어나는 지점이다. R01 S06 원칙(관통·합체 금지)을 지키는 가장 안전한 방법은 이렇다.
- 하강 클립은 **K07(틈이 남은 상태)에서 끝낸다**
- 다음 클립은 **접촉 직후**(빛 띠가 정 상단에서 막 출발, 먼지가 막 생기는 상태)에서 시작한다
- 편집에서 두 클립 사이에 금속 타격음을 정확히 얹는다. 시청자 눈에는 접촉이 보이고, 생성 모델은 접촉 프레임을 그리지 않는다

### 실패 시 대안 (Flow 안에서 해결)
| 리스크 | 신호 | 대안 |
|---|---|---|
| 단면 모형이 클립 중 모핑된다 | 피스톤이 늘어나거나 부품 개수가 바뀐다 | 해당 구간을 **정지 키프레임 + INFO 모션**(R01 그래픽 타임라인)으로 대체한다. 원리 장면은 정지 상태여도 성립한다 |
| 피스톤과 정이 합쳐진다 | 경계선이 사라진다 | 액션 컷으로만 처리하고, 접촉 프레임은 생성하지 않는다 |
| 3라운드 연속 K04가 실패한다 | 질소실 위치가 계속 바뀐다 | **이 구간만** R01의 Blender 리그로 렌더해서 Flow 외관 컷 사이에 넣는다(하이브리드). Flow 단독 원칙의 유일한 예외로 기록한다 |

| 질소가 부족하면 타격이 약해진다 | 사용 가능 | 제조사 정비 블로그 기준: 질소압이 낮으면 타격력이 떨어지고, 힘이 약하거나 진동이 크면 재충전이 필요하다. 과충전도 성능을 떨어뜨린다. 업로드 전에 **R01 S4(NPK 툴 매뉴얼 13쪽 가스압·피스톤 가속)**에서 같은 취지 문장을 확인해 S7로 등록할 것 |
| 기름은 거의 압축되지 않고 가스는 압축된다 | 사용 가능 | 기초 유체역학. 작동유의 체적탄성계수는 기체보다 수천 배 크다 |
| 활시위 비유 | 사용 가능 | 비유다. "저장 → 해제 → 전달" 순서가 R01 단계 1~5와 일치한다 |
| 공기 대신 질소인 이유(불활성·건조) | **보류** | 일반적인 설명이지만 이번 검색에서 1차 출처를 확보하지 못했다. 고정 댓글 후보로만 둔다 |
| 중형 기종 1분 300번 이상 | 선택 사용 | R01 S3: GH-15 320~400bpm. "한 기종"으로 한정해서만 쓴다 |
