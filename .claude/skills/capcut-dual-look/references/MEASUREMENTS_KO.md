## 3. 통합 LUT

- 기본 적용 순서: `4K → Auto Adjust`. 순서는 사용 편의를 위한 기본값이지 원본 앱 내 두 필터의 합성 결과를 측정한 것이 아님.
- `BSK_4K_then_Auto_65.cube`: 기존 두 `.cube`를 tetrahedral 보간으로 적용한 뒤 65³ 해상도의 신규 `.cube`로 베이킹한 컬러 LUT.
- 무작위 RGB 10만 점에서 순차 두 LUT와 합성 65³ LUT의 평균 절대 채널 오차는 0~1 RGB 기준 약 **0.000175**. (색 공간을 통한 모델 보간 오차이며, 실제 이중 캡컷 적용본과의 검증 지표가 아님.)
- 색공간 및 광원 조건이 달라지면 캡컷과 일치하는 정도는 보장하지 않음. 반대로 배열하면 영상 느낌이 달라질 수 있음.
- 4K LUT의 추가 공간 선명화 미포함. 선택 `--sharpen mild`는 FFmpeg `unsharp=5:5:0.25:5:5:0.0`으로 임의적이고 절제된 부가 효과임.

## 4. 운영 가이드

- 첫 확인은 2초 프리뷰, 과채도·그림자 뭉침·흰 테두리·검정 클리핑 확인.
- 기본은 선명화 끔. 이미 3D 렌더링에서 샤프닝/노이즈 제거가 적용됐다면 이중 처리 금지.
- 출력 해상도 기본 보존, 프레임레이트 보존, 오디오 copy, H.264 MP4.
- 10-bit HDR, HLG, PQ, BT.2020, LOG는 직접 투입하지 말고 보정 전 SDR Rec.709로 관리.

## 5. 학습 범위 밖 색(순수 원색·네온)에서의 동작 — 2026-10-25 스킬 정리 중 확인

**해석과 운영 규칙**

- 자연스러운 중간 채도 색(피부, 금속, 탁한 청록, 회색)은 세 LUT 모두 색상 변화 ±8° 이내로 안정적이다. 바삭숏 3D 기계 숏폼의 CLEAN 영상은 대부분 이 범위에 있다.
- **고채도 시안·마젠타·네온급 색은 Auto LUT와 통합 LUT에서 검정으로 무너진다.** 유막 R08 자막의 청록 강조색, 네온 2.5D 오버레이, LED·UI 화면이 포함된 Flow 생성 클립이 여기에 해당한다. 이것이 LOCK 7번(자막·오버레이는 색보정 뒤 후합성)의 실측 근거다.
- 소재에 순수 원색 영역(사이버펑크 네온, 형광 안전색, 포화된 하늘·물 CG)이 있으면 4분할 비교에서 해당 영역을 반드시 보고, 무너지면 `--mode 4k` 단독(원색 보존이 가장 좋음)이나 미적용을 택한다.
- 이 표는 LUT 자체의 조회값이며 H.264 인코딩 전의 수치다. 비디오 출력에서는 크로마 서브샘플링으로 경계가 약간 더 번진다.
