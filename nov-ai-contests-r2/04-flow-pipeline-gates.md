## 1. 파이프라인 원칙

**모든 화면과 현장음은 Google Flow 안에서 만든다.** 편집기는 조립만 한다.

```
대본·사실 범위 잠금
  → [Flow 이미지 생성] 인물·소품·장소 기준 이미지 (LOCK)
  → [Flow 이미지 생성] 시험 컷 키프레임
  → [Flow · Veo 3.1] 시험 컷 영상 (Frames to Video / Ingredients to Video)
  → 시험 통과 판정
  → [Flow] 나머지 키프레임 → 영상 → 필요 시 Extend
  → [Flow] 네이티브 오디오에서 현장음·효과음 추출
  → [편집기] 분할 레이아웃·화면비 마스크·자막·믹스·출력
  → 규격·권리·내용 검수 → 접수
```

| 단계 | Flow에서 | 편집기에서 (CapCut 등) |
|---|---|---|
| 키프레임 | Flow 이미지 생성. 기준 이미지를 참조로 사용 | — |
| 영상 | Frames to Video(시작·끝 프레임 지정), Ingredients to Video(참조 이미지 최대 3장), Extend | — |
| 소리 | Veo 3.1 네이티브 오디오(현장음·효과음, 시험적으로 대사) | 믹스, 레벨, 무음 구간 |
| 글자 | **생성하지 않음** (한글 깨짐) | 자막·타이틀·날짜 스탬프·AI 고지 |
| 화면 효과 | — | 서울 2/3/4/9분할, 제주 4:3→16:9 마스크, Meta 플래시 흰 프레임·그리드 |
| 출력 | 1080p 업스케일 후 다운로드(현재 플랜에서 제공되는 옵션 확인) | 1920×1080, 24fps CFR |

> 기능 이름·참조 이미지 수·클립 길이·업스케일 옵션은 생성 시점의 Flow 화면에서 다시 확인합니다. 이 문서는 플랜별 크레딧·상업 이용 조건·워터마크 정책을 보증하지 않습니다.

### Flow 밖으로 나가는 예외 (명시적으로 기록)
| 예외 | 작품 | 이유 | 조건 |
|---|---|---|---|
| 한국어 대사·VO 사람 녹음 | Meta, 제주 | Veo의 한국어 대사 품질 불확실. 제주어는 생성 모델로 신뢰 불가 | Flow 시험 후 어색할 때만. 화자 동의서 보관 |
| 드럼 음원 | 서울 | 박자 그리드의 기준이 되는 연속 트랙이 필요 | Flow 네이티브 오디오로 먼저 시도. 실패 시 직접 연주 또는 권리 확인 음원 |
| 폰트 | 전체 | 자막 | 상업·영상 사용 가능한 라이선스(예: OFL) |

R1에 있던 'imagegen', 'Omni 1.1'은 R2 파이프라인에서 제외했습니다(사용자 원칙: Flow 단독 우선. 'Omni 1.1'은 명칭 미확인).

### 생성 규칙
1. **한 컷 = 핵심 동작 하나.** 한 프롬프트에 사건 두 개를 넣지 않는다.
2. **LOCK 블록을 매번 붙인다.** 복사 실수 방지를 위해 작품별 `prompts.md`에 LOCK을 맨 위에 두고 붙여 넣는다.
3. **기준 이미지 → Ingredients**로 인물·소품 일관성. 텍스트 묘사만으로 일관성을 기대하지 않는다.
4. **같은 문제로 3회 실패 → 단순화.** 카메라 이동 제거 → 구도 넓히기 → 컷 분리 순서. 같은 프롬프트 무한 재생성 금지(R1 규칙 유지).
5. **글자·로고·실존 브랜드는 프롬프트에서 항상 배제.**
6. 클립에서 쓸 부분은 1~3초인 경우가 많다(특히 서울 패널). **정점 동작이 있는지만** 보고 채택한다.

## 2. 파일 구조와 이름 규칙

```
<작품코드>/                       SEO(서울) · MTA(Meta) · JJU(제주)
  00_lock/        기준 이미지 (예: MTA_LOCK_mother-present_v2.png)
  01_keyframes/   키프레임    (예: SEO_S06_KF_R1_t3.png)
  02_clips/       Flow 원본   (예: JJU_J06_R2_t1_ext1.mp4)
  03_audio/       추출 현장음, 녹음 원본, 동의서 스캔
  04_edit/        편집 프로젝트, 최종 MP4, 섬네일
  prompts.md      실행한 프롬프트 원문 + 사용 기능 + 참조 이미지 ID (예정본 아님)
  ai-log.md       §5 템플릿
```
Flow 프로젝트는 작품별로 하나씩 만들고 **삭제하지 않습니다**(생성 이력 증빙).

## 6. 품질 게이트

### 공통 (R1 유지)
- **내용**: 주제와 인물의 목표가 첫 12초 안에 이해되는가? 마지막 행동이 앞선 문제에 답하는가?
- **사실**: 실제 지역·시설·정책과 창작 미래를 구분했는가? 불필요한 수치나 완료 성과를 만들지 않았는가?
- **시각**: 얼굴·옷·소품 방향, 문·창 수, 기계 연결점이 유지되는가?
- **음성**: 현재 컷에 없는 내용이 먼저 들려 혼란을 주지 않는가? 말을 빠르게 읽어 억지로 맞추지 않았는가?
- **소리**: 군중 규모와 박수·잔향 규모가 일치하는가? 저작권 불명 음원이 없는가?
- **규격**: 길이·해상도·프레임·코덱·용량·표기·섬네일이 실제 요강과 맞는가?
- **증빙**: 계획본을 생성 완료 증거로 제출하지 않았는가? AI·사람 기여를 실행 결과대로 적었는가?
