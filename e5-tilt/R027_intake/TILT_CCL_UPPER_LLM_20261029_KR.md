## 2. C — Context / 작업 계약

- 대상: E5 신칸센의 공기스프링 스트로크식 차체 기울임 원리를 설명하는 세로 공학 쇼츠. 현재 인계 범위는 R025 입력 이후 R026c 수정 및 D드라이브 이관까지다.
- 사용자 요청: 레퍼런스 수준을 목표로 형상·쉐이딩·텍스처·카메라/전환·리깅을 보완하고 원래 영상 구성을 개선한다.
- 기존 로컬 자체 제작 에셋과 기존 원음을 활용한다. 구매 에셋/실차 OEM CAD로 표현하지 않는다.
- 기존 기계 운동과 최대 1.5°를 보존하고 접촉부 및 시각적 설명을 보완한다. 화면 글자·숫자·로고는 생성하지 않는다.
- 오케스트레이터가 통합·최종 검수를 맡고 에셋/표면·사실/음성·독립 QA 역할을 나눴다. GPU 렌더 작성자는 root 한 명이었다. 기존 사용자 Blender 프로세스는 종료하지 않았다.

## 3. C — Changes & Checks / 수행 작업과 근거

### 형상 및 리깅

1. 로컬 E5 차체와 곡면 운전실 창의 메시만 재사용했다. 원본 에셋의 부모·애니메이션·드라이버·외부 재질 의존성은 가져오지 않았다.
2. 차체의 초록/흰색/분홍 면별 도색 정보를 복구했다. 고밀도 차체 메시의 불필요한 평면 분할을 정리했다.
3. 차체 하부와 공기스프링 상판 사이 빈틈을 양쪽 불투명 하중 받침으로 연결했다. 국소 투명화 중에도 받침이 보이도록 했다.
4. 벨로우즈마다 기존 자세 데이터 기반 보정 키 9개와 원래 스트로크를 함께 베이크하여 상판의 이동/기울기를 추종하게 했다. 상단 기존 약 8mm 틈과 측방 불일치를 보정하고 하단 고정을 유지했다.
5. 원래 차체·대차·윤축 운동은 유지했다. 보호 코드 6개와 rig_config를 보존했고, 물리 NPZ 배열 40개는 로컬 재현 기준과 정확히 동일했다. 원래 다른 OS 기준과의 최대 약 1.45e-15 차이는 별도로 기록했다.

### 재질·조명·장면 연결

6. 차체 도색을 희게 씻던 환경 반사를 낮추고 고무/도장 프레임/노출금속의 거칠기와 구분을 조정했다. 기구 확인용 부드러운 조명을 추가했다.
7. 객실 창과 컵 구도를 조정하고 차체 하단을 국소 투명화해 내부 기구를 드러냈다.
8. 기존 원음의 실제 의미와 컷을 맞췄다. C04 컵 진입 → C05 공기스프링 변화 → C06 감소한 컵 쏠림 → C07 최대 1.5° 설명 → C08 외부 복귀 → C09 루프 연결이다. 제안 대본과 원음이 달랐던 부분을 조정했다.
9. E5 실차 상세 제어로 확인되지 않은 동시 급기/배기 화살표는 제외했다. 기존 원음을 재사용하고 로컬 ASR로 임시 단어 시각을 확보했다. 신규 VO 구매/생성이나 외부 업로드는 하지 않았다.

## 4. L — Limits & Next Actions / 미해결 및 다음 작업

완료 선언 금지 항목:
1. 동작량 평균 9 및 no_static_second는 FAIL이다. 레퍼런스급 품질 전체 승인 상태가 아니다.
2. 정상속도 1× 전체 시청, 실제 음성 청취, 실제 휴대전화 검수는 미수행이다. 전수 디코드/정지 표본 검토를 연속 시청으로 대체했다고 쓰지 않는다.
3. ASR 시각은 임시 추정이다. 모든 명사 선행 노출, 강제정렬, 실제 발화 정확도는 미검증이다.
4. 2Mbps 4초 스트레스 영상은 생성했으나 정상속도 압축 깜박임 검수는 미수행이다.
5. 원음 약 -18.02 LUFS / -1.49dBTP. 새 SFX, 최종 믹스/정규화, 자막, 1080p 납품 렌더, 게시 미수행이다.
6. 일반화된 설명용 대차다. OEM 치수·실차 부품 배치·하중/공압 성능·전체 쌍의 연속 충돌·서브프레임 전수 검증을 완료했다고 주장하지 않는다.

권장 후속 순서:
1. 전체 MP4를 1×로 실제 시청/청취하고, 휴대전화에서 컵/1.5°/공기스프링의 판독성을 확인한다.
2. 객실과 정면 설명 구간에 실제로 통과하는 창밖 기준물 및 적절한 구도/객실 시각 정보를 보완한다. 틸트 각도 과장이나 검사 임계값 하향으로 해결하지 않는다.
3. 수정 영향 범위의 접촉/리깅·카메라·재질 검사를 재실행하고, 같은 방법으로 동작량/루프/음성 동기화를 재측정한다. 이미 통과한 전체 검사를 이유 없이 확대하지 않는다.
4. 신규 버전 폴더/Blend로 저장하고 540p 재검수한다. 기존 R026c 동결 마스터와 원본은 보존한다. GPU 렌더는 하나씩 실행한다.
5. 사용자 품질 승인과 납품 범위 확인 후에 고해상도 최종 렌더/믹스/자막/게시를 별도 진행한다.
