## 2. 핵심 연출 컨셉 — 「투시 도면 (X-ray Blueprint)」

> **Blender 세계는 별개의 그래픽이 아니라, Flow로 본 현재의 지하 공간을 '투시해서 뼈대만 남긴' 같은 공간이다.**

두 세계를 '다른 영상'이 아니라 **같은 공간의 두 노출**로 묶습니다. 관객이 처음 몇 번의 전환에서 "실사 → 뼈대"의 대응 규칙을 배우면, 이후 40번의 전환은 끊김이 아니라 **설명의 리듬**이 됩니다.

### 2.1 대응 사전 (다섯 개의 모티프)

| 모티프 | 실사(Flow)에서 | 도면(Blender)에서 | 첫 등장(교육 컷) |
|---|---|---|---|
| **M1 선** | 바닥 유도선·점자블록 | 청록 피난선 | S014→**S015**→S016 |
| **M2 기둥** | 승강장 기둥 | 회색 기둥 2개 | S006→**S007** |
| **M3 천장** | 천장 패널 라인 | 회색 연기층의 윗면 | S004→**S005** |
| **M4 문** | 출입문·방화문 | 흰 판(문 블록) | S037→**S038** |
| **M5 빛** | 형광등 줄 | 조명 단계(밝기 스텝) | S092→**S093** |

규칙: **경계를 넘을 때 최소 한 개의 모티프가 같은 화면 위치에 남아 있어야 한다.** 이게 "자연스러운 연결"의 정의입니다.

### 2.2 색·조명 공통화
- Flow: 하이키를 **−0.7 ~ −1 stop**, 채도 −15%, 화이트를 Blender 바닥의 차가운 회백색에 맞춤. 블랙을 살짝 들어 Blender 배경 검정(#0B0F14 계열)과 같은 바닥.
- Blender: 실사 쪽 렌즈 감각을 빌려 **미세 그레인 + 약한 비네팅 + 0.3px 할레이션**을 컴프에서 추가.
- 결과 목표: 경계 휘도 점프 **|Δ| ≤ 40** (현재 최대 119).

## 3. 전환 문법 7종

| 코드 | 이름 | 무엇을 하는가 | 도구 |
|---|---|---|---|
| **T1** | 기하 매치컷 | 기둥·문·소실점·창을 **같은 화면 좌표**에 두고 하드컷 | Flow 재생성 시 키프레임을 Blender 구도로 만듦(Nano Banana → Omni I2V) |
| **T2** | 스타일 트윈 디졸브 ★ | Flow 클립을 Omni v2v로 **'도면화'한 쌍둥이**를 만들고, 원본↔쌍둥이를 Flow 컷의 머리 또는 꼬리 10–18f에서 크로스페이드 | Omni v2v |
| **T3** | 브리지 생성 | Flow 슬롯 자체를 다리로 재생성: 첫 프레임 = 앞 Blender 끝 구도의 실사판, 끝 프레임 = 뒤 Blender 첫 구도의 실사판 | Omni 첫/끝 프레임 |

| **T6** | 사운드 브리지 | 다음 컷 소리를 6–15f 먼저(J컷) 또는 이전 소리를 끌고(L컷) 넘김 | 사운드 |

### 3.1 왜 T2가 핵심인가
Omni 1.1 편집은 **"지정한 것만 바꾸고 프레이밍·움직임·언급하지 않은 것은 그대로 둔다"**. 그래서 원본과 도면화 쌍둥이는 **픽셀 단위로 정합**합니다. 정합된 두 영상을 크로스페이드하면 고스트(이중상) 없이 **공간이 그 자리에서 뼈대로 변하는** 것처럼 보입니다. 일반 디졸브와 달리 형태가 겹쳐 흐려지지 않습니다.

```
[Flow 원본 S015]───────────────┐
                              ├─ 꼬리 14f 크로스페이드 ─▶ [쌍둥이: 회색 매스·검은 배경] ─▶ 하드컷 ─▶ [Blender S016]
[Omni v2v 쌍둥이 S015-DG]──────┘                              (청록선만 M1으로 남음)
```

### 3.2 Blender 픽셀 불가침 원칙
AI 스타일 변환은 **Flow 쪽에서만** 일어납니다. Blender 컷 픽셀은 생성 모델을 거치지 않으므로 기존 QC 근거·사실 정보·라벨이 보존됩니다. (예외: §4.2 J-REALIZE는 Blender를 **입력**으로 쓰지만 결과물은 Flow 슬롯에 들어갑니다.)

## 4. Omni 1.1 Flash 활용 설계

### 4.1 확인된 사양(공개 자료 기준, 2026-10)

| 항목 | 값 |
|---|---|
| 편집(v2v) 입력 | **3–10초**, 32 MB 미만 |
| 편집 동작 | 지정한 변경만 적용, 프레이밍·모션·미언급 요소 유지. 전면 리스타일 가능 |
| 레퍼런스 영상 | Flow에서 **3초 클립 최대 3개** (모션·캐릭터·장면 디테일 유도) |
| 첫/끝 프레임 | 두 스틸 사이 보간 생성(전환·카메라 이동용) |
| 출력 | 3–10초(기본 8초), **24fps**, 16:9/9:16 |
| 해상도 | 360p·720p 네이티브, 1080p·4K는 업스케일 |
| 연장 | 10초씩 최대 40초 |

> 접속 차단으로 1차 문서를 직접 열지 못했고 검색 결과 요약 기준입니다. **파일럿 첫날 Flow UI에서 위 수치를 재확인**하세요(특히 v2v 입력 하한·레퍼런스 개수·출력 fps).

### 4.2 Omni 작업 유형 6종 (프롬프트 템플릿)

모든 프롬프트 공통 **LOCK 블록**(Flow 프롬프트 끝에 붙임):
```
LOCK: keep exact framing, camera path, timing and all geometry.
NO people, NO faces, NO flames, NO fire, NO text, NO letters, NO numbers,
NO logos, NO brand livery, NO station names, NO signage words.
Present-day, unbranded, location-unspecified Korean-style metro interior.
```

**J-DIAGRAM** (T2 쌍둥이 — Flow → 도면)
```
Restyle the whole shot into an architectural massing model:
matte mid-grey surfaces, edges kept crisp, all textures and reflections removed,
background and ceiling void fall to near-black (#0B0F14), soft top light,
floor a cool pale grey. Keep only [M-motif] in flat teal (#2FB3B8).
<LOCK>
```

**J-REALIZE** (Blender 클레이 애니 → 실사. 움직임 타이밍을 Blender가 결정)
```
Turn this grey clay previs into a photoreal present-day metro [subject].
Keep every object position, the exact motion and its timing frame-for-frame.
Brushed stainless steel, fluorescent ceiling light, clean terrazzo floor.
<LOCK>
```
용도: S091/S092 문 열림→닫힘(현재 S092 결함), S071 열차 진입·정지, S100 장치 와이드, S062 깊은 축 승강장. **모션·타이밍을 프롬프트 운에 맡기지 않고 Blender로 고정**합니다.

**J-BRIDGE** (T3 — 첫/끝 프레임)
- 첫 프레임: 앞 Blender 컷 마지막 프레임을 Nano Banana로 실사화한 스틸(구도 동일)
- 끝 프레임: 뒤 Blender 컷 첫 프레임 구도의 실사 스틸
```
Slow continuous [dolly/pan] from the first frame to the last frame,
same space, same lens, no cuts. <LOCK>
```

**J-MOTIONREF** (T4)
- 레퍼런스: Blender 해당 컷의 카메라 이동 3초(클레이 렌더 가능)
```
Match the camera move of the reference video (direction, speed, height)
while showing [Flow subject]. <LOCK>
```

**J-FIX** (부분 편집)
- 예: S092 꼬리 `The doors slide fully closed between 0.4s and 1.6s.` / S092→S093 `The ceiling fluorescent lights dim one step at 2.6s.`

**J-GLOW** (S110/S111 전용)
```
Same shot with all ambient light off; only the photoluminescent
emergency-release marking glows soft green. <LOCK>
```

**하지 않는 것:** Blender 컷을 Omni로 리스타일, 실사 공간에 사실적 연기를 채우는 편집(재연·오인 위험), 워터마크를 크롭·인페인트로 제거.

### 4.3 3초 하한 대응 — 핸들 규칙
- Flow 재생성은 항상 **8초 원본**을 만들고 컷은 그 안에서 고릅니다. v2v 쌍둥이도 **8초 원본 전체**에 걸고, 원본과 쌍둥이를 **같은 in/out으로** 자릅니다.
- Blender를 v2v/레퍼런스 입력으로 쓸 때(J-REALIZE·J-MOTIONREF): .blend 타임라인에서 앞뒤 핸들 포함 **≥3.2초**로 클레이 렌더. 핸들이 없으면 마지막 프레임 홀드로 패딩(레퍼런스에는 움직임 구간만 3초 잘라 넣음).

### 4.4 24 → 30fps 정합
1. 모든 Omni 출력은 24fps 마스터로 보관.
2. 원본과 쌍둥이는 **동일 알고리즘·동일 파라미터**로 30fps 변환(광학흐름 보간; 고정 카메라는 프레임 블렌드 허용). 다르게 변환하면 T2 정합이 깨집니다.
3. 변환 후 컷 프레임 수를 큐시트 범위와 대조(예: S007 = F480–F511, **정확히 32f**).

### 4.5 해상도·질감 맞춤
- 1080p(가능하면 4K 생성 후 1080 다운샘플)로 받아 선명도 확보.
- 두 세계에 **같은 그레인 플레이트**를 최종 단계에서 일괄 적용 → 네이티브 해상도 차이를 가림.
