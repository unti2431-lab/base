## 1. P1 — 13–19 s(C4, F381–569) 주머니 변화

### 1.1 진단 재정리
- 대사 4문장은 두 절로 되어 있고 각 절의 주어가 다르다: ①"바퀴를 들던 공기주머니에서는 공기가 빠지고" → 리프트 주머니, ②"아래로 누르는 주머니에는 공기가 들어갑니다" → 하중용 주머니.
- 리프트 주머니: 0.83 → 0.72 → 0.63 (−24 %, 6 s). 하중용: 0.010 → 0.019. **두 변화 모두 시청자 역치 아래.**
- 그런데 기하학적으로는 큰 변화가 있다: 하중용 주머니 높이 0.169 → 0.317 m(**1.9배**). 축 전체 구도(C4 창 v 0.22–0.74, 채움 1.0)에서는 9 cm 하강이 작아 보이지만, 주머니만 잡으면 높이가 두 배가 된다. 안 보이는 것은 물리가 아니라 **발광 기준과 프레이밍**이다.

### 1.2 해법 ① 발광 기준 = 절대압 × 체적 (D-R4-1)
- 이상기체에서 공기량 n ∝ p_abs·V. 게이지압×체적은 "공기량"이 아니다. LOCK 문구 "청록 발광 = 주머니 공기량(압력 × 체적)"의 **해석 정정**이지 완화가 아니다. 그래도 절차대로 LOCKS에 기록한다(초안 §8).
- 구현 위치: 표현 층 `build_scene_lift.py`에서만. `R["p_ride_bar"]`, `R["h_ride"]`, 리프트 주머니 p·h도 같은 식으로 재계산. `lift_kin.solve()`·하위 함수 수정 금지.
- 정규화: 1.0 = 영상 안 최대 공기량(적재 후 하중용 주머니). 인계서 추정값으로 하중용 주머니는 하강 중 0.18 → 0.34.
- **부작용 점검**: 절대압 기준에서는 어떤 주머니도 완전히 꺼지지 않는다(대기압 바닥 ≈ 0.1–0.18). "빠짐 = 꺼짐"이 "빠짐 = 흐려짐"으로 바뀐다. 접지 후 리프트 주머니(F591–606)의 "완전 꺼짐" 연출도 같이 흐려짐으로 바뀌므로, 적재 전 빈 하중용 주머니와 접힌 리프트 주머니가 비슷한 어둡기인지 시트로 확인한다.
- 증거: `evidence/emission_curve_R04.csv`(F, lift_old, lift_new, ride_old, ride_new) — 베이크 npz에서 바로 계산 가능, 렌더 전에 뽑는다.

## 3. P3 — 강조 방식 (D-R4-3)

- `emph_post.py` k = 1.0(비강조 어둡게 하기 폐지). 12F 램프·8F 교차 코드는 남겨 두고 k=1.0으로 무효화.
- 강조의 본체는 **프레이밍**(§1.3)이다. 보조로 **명사 발화 순간 윤곽 플래시**: VO_WORDS의 명사 첫 발화 F(공기주머니·주머니·막대 등)에 대상 Cryptomatte 마스크의 가장자리 2 px(540p 기준, 1080p는 4 px) 청록 윤곽을 0.4 s(12F) 한 번 켜고 끈다. 2.5D 후합성 도형이라 정책 위반 아님. 한 색 한 의미: 청록 = 공기/주머니. 막대·링(주황·빨강)에는 윤곽을 쓰지 않는다.
- 발광 이득 ×1.4 안은 **채택하지 않는다**: 발광 = 공기량이라는 LOCK 의미가 깨진다(강조 중 주머니가 "공기가 많아 보임").

## 5. P5 — Q5 오해 "하중이 줄면 내려온다"

### 5.1 원리
무음 1차 시청에서 **막대 = 하중, 점선 = 한계**를 배우지 못하면 이후 모든 인과가 뒤집혀 읽힌다. 가르치는 방법은 세 가지를 같은 장치로 반복하는 것이다.

1. **배움(C2, 적재)**: 크레인(`yard_crane.py`)이 화물을 내릴 때마다 막대가 한 단 오른다(화물 착지 F ±2F 동기). 막대가 "무게"라는 것을 사건으로 가르친다. R03에서 적재와 막대 상승이 동기인지 확인(§9-③).
2. **넘음(F163 '넘으면')**: 막대 주황 → 빨강, 기준선 깜빡임 2회, 0.5 s 홀드, 기준선 → 제어기 펄스(§2.2-1). 이 펄스가 7–9 s의 "스스로"로 이어져 인과 사슬이 끊기지 않는다(티저 삭제 효과).
3. **거울상(C7a F871–951 '하중이 충분히 줄면')**: 같은 막대가 기준선 **아래로** 내려오고 빨강 → 주황, 기준선 깜빡임 2회, 같은 경로 펄스 → 상승. "위 = 내려옴, 아래 = 올라감"이 두 번 쌍으로 보이면 뒤집어 읽을 수 없다.

### 5.2 구현
- `ovl_lift.py` 막대 블록: 색 상태(normal/over), 기준선 깜빡임, 홀드, 펄스 출발점 추가. 색은 기존 신호 색(주황·빨강)과 의미를 통일(주황 = 정상 범위, 빨강 = 한계 초과/거부).
- 타이밍은 VO_WORDS에서 '넘으면'·'줄면'·'과부하'·'막' 첫 발화 F를 읽어 plan_ref 규칙(L-G01 ±0F)과 맞춘다. 앵커 규칙은 바꾸지 않는다.

### 5.3 검증
- 검수 페이지 무음 열린 질문 A에서 "막대/점선이 무게·한계"로 답하는 인원 ≥ 3/5.
- Q5 오해 반복 0.

### 6.4 P9 기술 부채
- **구간 클립 2단계 먹스**(`scripts/encode_anim.py`):
  ```bash
  # 1) 영상만 잘라 copy
  ffmpeg -y -i full.mp4 -ss {t0} -t {dur} -an -c:v copy seg_v.mp4
  # 2) 음성은 wav에서 같은 창을 잘라 패딩, 길이 고정 후 먹스
  ffmpeg -y -i seg_v.mp4 -ss {t0} -t {dur} -i audio/lift_vo_mix48k.wav \
    -af "apad" -t {dur} -c:v copy -c:a aac -b:a 192k -movflags +faststart seg.mp4
  ```
  한 번에 하려면 `-shortest` 대신 `-fflags +shortest -max_interleave_delta 100M`을 쓰면 apad가 먼저 끊기는 문제가 사라지지만, 2단계가 결정적이라 2단계를 기본으로.
- 검수 페이지 v4: `lift_silent.mp4`(`-movflags +faststart`)·`lift_vo.mp4` 교체, 상단 버전 표기 R04, 집계는 같은 영상끼리만(D-R4-5).
- R04 540p 전편에서 미수행 측정 실행: L-G13 명사 첫 노출(VO_WORDS vs 대상 첫 노출 F), L-G17 ΔE 샘플, L-G18 노면:타이어, L-G19 밴드 on:off. 결과는 `evidence/verify_render_R04.json`.
- SFX 큐: 티저 삭제로 신규 사건은 범퍼 타격(F?)·유령 막대 수축·거부 링만. `audio/SFX_CUES.csv`에 R04 사건 추가(사건 F ±1F).
