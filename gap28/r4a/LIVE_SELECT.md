## 3. 설계에 미치는 영향 (R4 계획서 수정 포인트)

1. **촬영된 문에는 발판이 있다.** 152209·152835 에서 승강장 문턱에 천공 강판 발판 + 노란 쉐브론이 보이고, 열차가 오면 발판 끝 검은 고무 빗살이 차체에 닿는다. 실사 = "해법이 있는 오늘의 상태", CG = "그 아래와 발판 없는 위치(x=4.2)의 설명"으로 역할을 나눈다. 촬영 문의 승차위치 번호는 화면·음성에 말하지 않는다(NOT_DECIDABLE "3-3 설치 현황").
2. **CG 발판의 외형**: 실사 발판은 천공 아연도금 강판 + 노란 쉐브론이다. 현재 CG 는 민무늬 시안 판. 실사와 이어지려면 CG 판도 천공 강판으로 가고 **시안은 끝단 띠로만** 남기는 안을 제안한다(STYLE "시안 = 해법" 유지). 사용자 결정.
3. **스크린도어 모델링 규격**(계획서 §5): 회색 프레임, 어두운 유리, 문턱 발판 폭, 쉐브론 띠. 실사에서 역설계한다. "발빠짐 주의" 스티커 자리는 **빈 면**으로 둔다(NO TEXT).
4. **B13 종료 구도**: 전환 B 를 가림 와이프로 하면 B13 은 설계대로 수직 부감으로 끝내도 된다. 물질화로 하면 B13 끝 포즈를 152209 삼각대 포즈(높이 약 1.3 m, 약 45° 부감)로 바꿔야 한다.
5. **B01 시작 포즈**: L2 가 열차 안에서 틈을 내려다보는 포즈이므로 B01 `p0` 는 차체 쪽(+dy)에서 시작한다. 현재 설계 `[0, 0.142, 4.4]` 는 승강장 상공이라 바뀐다.
6. **실사 안의 텍스트**: L1·L4 프레임 좌상단에 스티커 모서리가 걸친다(붉은 삼각 경고 표지). 면적 2% 미만이라 허용하되 1080 크롭에서 가능한 한 밖으로 민다.
