## 5. 리그 LOCK

### 5.1 공통 좌표·대칭
- 월드 Z가 위, 연결축은 Y. 헤드 A는 −Y 쪽에서 +Y를 바라본다.
- **헤드 B = A의 링크 인스턴스를 Z축으로 180° 회전**해 배치한다. `scale`에 음수 금지. QC에서 `det(matrix_world[:3,:3]) > 0`을 확인한다.
- 회전 부호: 각 헤드 로컬 +Z에서 내려다본 반시계 방향 = +θ. Z축 회전 인스턴스라 A와 B에 같은 부호 규약이 그대로 적용된다.
- 모든 기하 수치는 `rig_config.json` 하나에 둔다. 각 항목에 `source`(S/D/P/V)와 `status`(LOCK/HOLD/CONCEPT)를 적는다.

### 5.2 TEST A — 시바타 계열 (150F, 샷06과 동일 프레임·카메라)
- 1DOF 수직 피벗 회전정, 복원 스프링, 원호 쐐기면 접촉.
- θ값은 HOLD 상태라 CONCEPT_ONLY 워터마크 블로킹만 허용한다. 정확성 승인은 G0-B 이후.
- QC 항목:
  - 피벗 1DOF 유지
  - 회전정–돌기–잠금실 관통 0, 설계 접촉 목록 별도
  - 스프링 와이어 직경 일정
  - 사건 F 3종을 `geometry_qc.json.events`에 기록

### 5.3 TEST B — 샤르펜베르크 계열 (150F, 샷10과 동일 프레임·카메라)
- 원판: 수직 주 핀 1DOF. 고리: 원판 링크 핀에 힌지. 장력 스프링 복원.
- 체결 후 폐루프(피벗 A–원판 A–고리–노치 B–피벗 B, 그리고 대칭 경로)를 해석적으로 풀어 배치한다.
- QC 항목:
  - 고리 길이 오차 ≤ 1e-5 m
  - 폐루프 닫힘 오차 기록
  - 관통 0
  - 사건 F 3종 기록
- 개념 리그로만 제작 가능(G0-C). 차량명 없음.

### 5.4 4초 게이트 (G3)
- 각 테스트에서 **[E−60, E+59]** 120F를 판정한다. E는 각각 JP_LOCKED, SCH_LOCKED 베이크 사건 F.
- 540p, 인코딩본을 정상속도로 판독하고 저비트레이트 스트레스 테스트도 한다.

- S2의 첫 문장(F190–약 F275)과 S3의 첫 문장(F640–약 F725) 뒤에는 각각 사건까지 무음 구간을 둔다.
