## 5. 타임라인 (T03)

### 5.1 컷 길이 규칙
- 24 fps, `t = (F − 1) / 24`, 컷은 시작 포함·끝 제외.
- 모든 컷 **72F 이상 96F 이하**(3.0~4.0초). 마지막 C18만 루프 꼬리를 위해 최대 96F.
- 전체 프레임 = round((음성 길이 + 꼬리) × 24). 말소리는 자르거나 늘리지 않는다.
- **꼬리(C18)**: 마지막 문장 뒤에 앰비언스만 있는 루프 꼬리를 붙인다. 길이는 C18이 72~96F가 되도록 T03이 정한다(보통 2.5~3.5초). 꼬리 소리는 C01 시작 0.5초의 앰비언스와 같은 질감으로 하고, 루프 재생 시 이음에서 끊김이 없어야 한다.

### 5.2 컷 경계 위치 규칙
- 경계는 **음성 무음 구간 안**(단어 사이 간격 ≥ 120 ms)에서, 다음 단어 시작 **2~4F 앞**에 둔다.
- 문장 중간 컷은 아래 쉼표 지점에서만 허용한다.

| 허용 지점 | 이유 |
|---|---|
| "시속 200킬로미터라면, ⏐ 비상제동을 걸어도…" | 조건 → 결과 |
| "첫째, ⏐ 선로 속 케이블이…" / "둘째, ⏐" / "셋째, ⏐" | 열거 표지 뒤 |
| "사고 당일, ⏐ 첫 번째 장치가…" | 시간 표지 뒤 |
| "보도에 따르면, ⏐ 앞 열차가…" | 출처 표지 뒤 |
| "앞 열차가 서 있는 상황에서, ⏐ 뒤 열차에…" (쉼 ≥ 120 ms일 때만) | 상황 → 사건 |
| "규정상 이럴 땐, ⏐ 눈으로 보고…" (P1) | 조건 → 규정 |

- **금지**: 숫자와 단위 사이, "LZB"·"ASFA"·"관제사" 앞 3F 이내, "운행 재개 허가" 내부, 문장 마지막 어절 내부.
- 경계를 정하는 방법: `CUTS_R4.csv`의 `anchor_text`와 `split_after`로 후보 지점을 찾고 → 무음 구간 안의 프레임으로 맞추고 → 각 컷이 72~96F가 되도록 동적 계획법으로 고른다. 해가 없으면 허용 지점 표를 넓히지 말고 중단·보고한다.

## 6. 2.5D 렌더러 (T04)

생성 모델이 아니라 **스펙 JSON을 읽어 같은 결과를 내는** 렌더러를 만든다. Blender가 작업 PC에 있어도 이번 R4는 Python 렌더러로 한다(설치·버전 문제 없이 재현되게). 위치: `tools/r25d/`.

### 6.1 구조
```
tools/r25d/
  render.py          # spec.json → PNG 시퀀스 (1080x1920, 24fps)
  layers.py          # 판(plate), 도형, 경로, 라벨, 펄스
  camera.py          # 패럴랙스 카메라: pan/zoom/dolly, 레이어 깊이 z로 이동량 계산
  ease.py            # easeInOutCubic 등 (프레임 정수 기준, 난수 시드 고정)
  qc_palette.py      # 색 사용 검사
specs/C03.json … C18.json
```

### 6.2 깊이 레이어 모델
- 각 레이어는 깊이 `z`(1.0 = 기준면, 클수록 멀다)를 가진다. 카메라 이동량 `d`일 때 레이어 이동 = `d / z`, 줌 `s`일 때 배율 = `1 + (s − 1) / z`.
- 판(plate) 레이어는 Flow 클립의 **한 프레임**이나 단색·그라디언트. 판을 깊이별로 나눠야 하면(예: 근경 도상 / 열차 / 원경) 사람이 마스크 PNG를 만들지 않고, **수평 띠 3개로 나눈 뒤 가장자리를 24 px 페더**해 깊이를 다르게 준다. 형상이 찢어지면 그 판은 단일 깊이로 되돌린다.
- 카메라 이동 범위: 컷 전체에서 수평 이동 ≤ 프레임 폭의 4%, 줌 ≤ 8%. 회전 없음.

### 6.3 그래픽 원소
| 원소 | 설명 |
|---|---|
| `band` | 경로(폴리라인, 원근 적용) 위를 따라 자라는 반투명 띠. 길이 0→1 애니메이션 |
| `pulse_train` | 경로 위를 일정 간격으로 이동하는 작은 발광 점들. 방출 on/off |
| `ping` | 한 지점에서 한 번 퍼지는 원(ASFA 점 확인) |
| `marker` | 위에서 본 선로 위 점(열차 위치). 경로 매개변수 s로 위치 지정 → **항상 선로 위** |
| `radio` | 관제 아이콘에서 표적으로 가는 동심 호 3개 |
| `ribbon` | 열차 앞으로 펼쳐진 허용 속도 리본(높이 = 속도) |
| `label` | 라틴 문자·숫자 라벨(LZB, ASFA, km/h, m, km). Pretendard Bold |
| `note` | 화면 하단 고정 작은 한글 주석("개념도", "보도 기준") — **자막 레이어**로 렌더 |

### 6.4 색 (한 색 = 한 의미, 전 편 고정)
| 의미 | 색 |
|---|---|
| 정보 흐름(LZB) | 청록 `#2EC4B6` |
| 핵심 수치 | 금색 `#E9B949` |
| 정지 열차·정지 지점·적색 신호 | 주황-적 `#E4572E` |
| 후행 열차·중립 표시 | 청백 `#CFE3F2` |
| 꺼진 장치 | 회색 `#6B7780`(채도 0) |
| 배경 잉크 | `#0B1A22` |
| 관제·무전 | 청백과 같음(새 색을 만들지 않는다) |

깜빡임(점멸) 금지. 경고 느낌의 붉은색은 정지 열차·적색 신호에만 쓴다.

### 6.5 안전 영역
- 그래픽 핵심 요소는 프레임 높이 **8%~70%**, 폭 **6%~86%** 안에 둔다.
- 하단 25%는 자막·쇼츠 UI, 우측 12%는 쇼츠 버튼 영역. 이 영역에는 판과 중립 배경만.

### 6.6 질감 통일 패스
- 모든 컷(Flow·2.5D)에 같은 필름 그레인(강도 고정, 시드 = 프레임 번호)과 약한 언샤프(반경 0.6, 양 0.3)를 한 번 적용한다.
- 2.5D의 순수 그래픽 컷은 배경을 단색이 아니라 **해당 장면 판을 어둡게(노출 −1.5 EV)·흐리게(σ 12 px) 깐 것**으로 해서 실사 컷과 이어지게 한다.
