## 3. 프록시 사양 (에셋 도착 전까지 쓰는 것)

- 단위 미터. 값은 `src/config/rig_config.json`에서만 읽는다.
- 노즈: 길이 파라미터 `nose_length_m`(E5 15.0, EMU-370 10.2). 단면은 같아도 되지만 **노즈 길이·끝 높이·캡 위치가 파라미터에 따라 달라져야 한다.** 각 노즈의 실측 길이를 빌드 직후 출력하고 config 대비 ±1% 이내.
- 편성: E5 선두차 + 중간차 5, EMU-370 선두차 + 중간차 7(인스턴스). 차량 사이 간극 0.5 m.
- 대차 2개/차량, 축간 2.5 m(E5)·2.6 m(EMU), 차륜 지름 0.86 m, 궤간 1.435 m.
- 팬터그래프 프록시(상승 상태): `pantograph_cars` 위치, 습판이 전차선 아래 0.5–2 mm.
- 색: E5 상부 #0A7D5B / 하부 #F2F3F1 / 띠 #E2457D, EMU-370 #EDEFF2 + 회색 윈도우 밴드(UNVERIFIED 표기 유지).

## 4. 운동

- 열차 X(t) = x0 + v·t 등속(E5 88.89 m/s, EMU 102.78 m/s). 슬로모션·감속 금지.
- 차륜각 = v·t / 0.43. 대차 진동 3 mm·6 Hz, 차체 롤 0.15°.
- 베이크 범위 F0–F901, t<0 선형 외삽. 모션블러 ON, 셔터 0.5(C4 0.35, C5a 0.8).
- C3 X-Ray 구간도 열차는 달린다. 카메라는 hull 모드로 따라가고 배경·기둥이 흐른다.
