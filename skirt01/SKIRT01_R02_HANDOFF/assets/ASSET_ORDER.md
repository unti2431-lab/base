# ASSET_ORDER.md — 에셋 경제성 비교와 발주서

질문: "무료 에셋을 받는 것과 새로 모델링하는 것, 어느 쪽이 경제적·효율적인가?"

## 1. 먼저 — 살 수 없는 부품과 살 수 있는 부품을 가른다

| 부품 | 구매·다운로드 가능? | 이유 |
|---|---|---|
| 디플렉터(강성부·솔·끝단) | **불가** | 치수가 FAIL 기준. config에서 생성해야 QC가 성립 |
| 디딤판·빗판·스커트 패널 | **사실상 불가** | 4 mm 틈·빗판 맞물림·클리트 홈이 내용. 기성 에셋은 틈 0, 클리트 없음, 빗판이 평판인 경우가 대부분 → 어차피 다시 만든다 |
| 난간 유리·데킹·핸드레일·뉴얼 | 가능 | 실루엣·반사용. 치수 무관 |
| 역 환경(바닥·벽) | 가능하나 불필요 | 아웃포커스 명도 공급용. 평면 + 타일 텍스처면 충분 |
| **텍스처**(헤어라인 스테인리스·주조 알루미늄·타일) | **가능, 권장** | CC0 PBR 텍스처는 절차 노드보다 빠르고 품질 높음 |
| **HDRI**(실내 반사용) | **가능, 권장** | 스테인리스 반사 내용. CC0 |

즉 **외부 에셋이 기여할 수 있는 범위는 "난간 3부품 + 텍스처 + HDRI"뿐**이다.

## 2. 세 가지 안 비교 (난간 3부품 기준)

| 항목 | A. 자체 모델링 (bmesh 스크립트) | B. 무료 모델 (Sketchfab CC-BY / BlenderKit Free 등) | C. 유료 모델 (TurboSquid·CGTrader, 대략 2~8만 원) |
|---|---|---|---|
| 작업 시간(추정, 에이전트) | 1.5~2.5 h (유리 판 + 압출 핸드레일 프로파일 + 뉴얼 곡면 1종) | 0.5 h 탐색 + **2~4 h 정리**(단위·스케일 보정, 삼각화 해제, 베벨 재적용, 이름 규칙, 충돌 쌍 매핑, 재질 교체) + 실패 시 재탐색 | 0.5 h 탐색·결제 + 1.5~3 h 정리 |
| 치수 일치 | 완전 (config) | 낮음. 디딤판 폭 1.0 m·경사 30°에 맞춘 모델은 드묾 → 스케일 왜곡 또는 재모델링 | 중간 |
| 파이프라인 적합성 | 완전 (bpy.ops 금지·인스턴스·굽힌 베벨 규범 그대로) | 낮음. 모디파이어·bpy.ops 임포트·비정규 메시 | 중간 |
| 라이선스 | 없음 | CC-BY는 **설명란 표기 의무**가 3편(SCR-02·04 재사용) 모두 따라감. CC0는 품질 낮은 편. 상업 영상 허용 여부 개별 확인 | 표준 로열티프리는 대개 상업 영상 허용. 영수증을 LICENSES.csv에 |
| 품질 상한 | 깨끗한 제품 렌더에는 충분(유리·고무·금속 단순 형상). 뉴얼 곡면만 난도 있음 | 편차 큼. 저폴리·베이크 텍스처가 흔함 | 높음. 단 우리 재질 규범으로 교체해야 명도 3층이 맞음 |
| 재사용(3편) | 완전. config만 바꿈 | 가능하나 표기 의무 지속 | 가능 |
| 리스크 | 뉴얼 곡면이 밋밋할 수 있음 → G7에서 판단 | 정리 시간이 모델링 시간을 넘는 경우가 흔함(이 채널의 기존 판단과 일치) | 비용 + 정리 |

## 3. 결론 (권고 = 채택)

**A 자체 모델링 + CC0 텍스처·HDRI만 외부.**
- 난간 3부품은 단순 형상이라 자체 제작이 가장 싸고, 치수·규범·라이선스 리스크가 0이다.
- 무료 모델은 "정리 비용 > 모델링 비용"이 될 확률이 높고, 핵심 부품에는 어차피 못 쓴다.
- 유료 모델은 **G7 프리뷰에서 뉴얼·핸드레일 룩 격차가 확인될 때만** 예비안으로 연다(그때도 재질은 우리 것으로 교체).

핸드오프 R01의 "고정밀 에셋 + 자체 리그 권장"과 다른 결론인 이유: 그 권장은 트위스트락·wnut처럼 **복잡한 기성 부품이 주인공**인 편의 경험이다. 이 편의 주인공(디플렉터·틈·빗판)은 **단순 형상 + 정확한 치수**라서 구매가 품질을 올리지 못한다.
