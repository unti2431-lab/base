## 레퍼런스에서 가져올 것 / 버릴 것

가져올 것
1. **원테이크 연속 이동으로 부품 관계를 보여주는 방식** — 크랭크축→실린더 사이→프로펠러 축(9.9초). 우리 편은 C08→C09(끝단 위치→끝단 높이)를 한 번의 저각 트래킹으로 잇는다.
2. **첫 프레임에 전체 실루엣과 핵심 부위를 동시에** — 기체 + 열린 날개 단면.
3. **깨끗한 제품 렌더 + 단일 강조색** — 설명 영상에서 가장 잘 읽히는 룩.
4. 중망원 압축 원근.

버릴 것
1. 발사 글로우·폭발·입자 → 3D 씬 금지. 필요하면 후합성 도형.
2. 외피 반투명 X-ray → 우리 편은 투명이 아니라 **물리 단면**(컷터)로 보여준다. 반투명은 치수 비례 판독을 흐린다.
3. 번인 자막.
