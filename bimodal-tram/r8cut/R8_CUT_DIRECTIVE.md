**지시안의 핵심 설계 세 가지**
1. **비교는 "한 장의 기준 배경 + CG 오버레이"로.** 지금까지는 WET_A와 WET_B 두 생성 이미지를 비교했는데, 두 장의 배경 골재가 서로 달라 실험처럼 보일 수 없었습니다(R7 LIMITED 판정). R8에서는 **WET_CLEAN 한 장을 고정 배경으로 두고 통과선과 분포곡선을 CG로 그립니다.** 배경이 픽셀 단위로 같으니 달라지는 것은 그래픽뿐입니다. WET_A와 WET_B는 "실사 느낌 참고컷"으로 강등해 하드컷으로만 씁니다.
2. **CG는 '설명', Flow는 '실재감'.** 수치, 순서, 인과처럼 정확해야 하는 것은 CG(편집기)로만 만들고, 생성 영상에는 글자나 도식을 절대 넣지 않습니다. Flow는 바퀴, 센서, 정류장, 정비고처럼 "만질 수 있는 것"만 만듭니다.
3. **오프닝↔엔딩 콜백.** C001의 고스트 레일(점선 레일이 그려졌다가 ✕로 지워짐)이 C082에서 아주 옅게 다시 떠올랐다가 사라집니다. B03의 질문 칩 두 개("이끄는 일?", "버티는 일?")는 B07에서 답으로 회수됩니다.

## 2. 편집 원칙

### 컷 길이
- 기본 **3~4초**입니다. 같은 CG 배경 위에서 칩이나 노드가 하나씩 열리는 "CG 비트"는 1.5~2.5초도 허용합니다. 시청자에게는 컷이 아니라 정보가 한 겹 쌓이는 것으로 보입니다.
- 4.5초가 넘는 컷 11개는 모두 **읽어야 하는 문구**(근거, 한계 고지)이거나 **관찰 홀드**입니다. 이 컷들을 잘게 자르지 마세요.
- **관찰 홀드**: C030(+1.5초, 좁은 띠 관찰), C032(+1.0초, 평평한 단면), C037(+1.5초, 러팅 정의), C083(엔드 +3초). VO가 없는 구간으로, 타임라인이 그만큼 늘어납니다.

### 타임코드 읽는 법
- `tc_in/out`은 **현재 컷의 VO 무음 구간으로 역산한 추정치**입니다. 문장 경계는 ±0.5초, B12~B14 구간은 ±1문장까지 어긋날 수 있습니다. 실제 편집에서는 **`vo_segment` 열의 첫 단어 파형에 컷을 맞추고** `actual_in/out` 열을 채우세요.
- 컷 포인트는 VO 단어 시작 **2~4프레임 앞**에 둡니다. 화면이 먼저 바뀌고 말이 따라오게 합니다.

## 5. Google Flow 생성 작업표 (18건)

### 공통
- 기본은 **Frames to Video**(시작 프레임 = 기존 R7 자산)입니다. 시작 프레임이 없는 작업(FL06, FL11, FL12, FL14, FL15, FL16, FL17)은 **Ingredients**로 R7 자산을 참조로 붙이고 텍스트로 생성합니다. 계정에서 Ingredients를 쓸 수 없으면 Text to Video로 생성한 뒤 형상을 검수합니다.
- 클립은 8초로 생성하고, 검수를 통과한 구간에서 **서로 다른 3~4초 구간**을 골라 a/b/c/d로 나눠 씁니다. 같은 구간을 두 번 쓰지 않습니다.
- 생성 오디오는 전부 버립니다. 실행 전에 현재 계정의 모델, 해상도, 크레딧을 확인하세요.
- **공통 꼬리 프롬프트**(모든 작업 끝에 붙임):
```
Locked-off camera unless stated. Preserve the exact composition, colours, lighting and every object of the reference.
No text, letters, numbers, logos, signs, subtitles or UI. No people. No glow, sparks, smoke, beams, magnetic or magic effects.
No new vehicles unless stated. No morphing. Photoreal, natural restrained motion. No dialogue, no narration, no music.
```

## 7. 사운드

- VO: 현재 녹음을 유지하고, 컷을 VO에 맞춥니다(VO 재녹음 없음).
- BGM: 저역 지속음 위주의 미니멀 앰비언트. VO 구간 −18~−22 dB, 관찰 홀드(C030, C032, C037)에서 +3 dB 살짝 올렸다 복귀. 4장(청라 기록)은 BGM을 한 단계 더 낮추고 리듬 요소를 빼서 '기록' 톤으로 갑니다.
- SFX: 타이어 구름(C001, C002, C080), 센서 통과 '틱' 1회(C008), CG 칩 등장 소프트 클릭(−30 dB, 모든 칩에 넣지 말고 키워드에만), 단면 슬라이스 '휙'(C031), 엔딩은 구름음만 멀어짐.
- 마스터: **−14 LUFS 통합, 트루피크 −1.0 dBFS**. 현재 −20.6 LUFS.

## 8. 작업 순서와 검수

1. **VO 파형 위에 컷 포인트를 찍습니다.** `R8_CUTLIST.csv`의 `vo_segment` 첫 단어 기준으로 `actual_in/out`을 채웁니다. 이 시점에 추정 TC는 버립니다.
2. **가편집(정지 + CG 자리표시)**: Flow 클립 자리에는 시작 프레임 정지 이미지를, CG 자리에는 문구만 넣은 플레이스홀더를 놓고 템포를 먼저 확정합니다. 3~4초 리듬이 어색한 곳은 이 단계에서 컷을 합치거나 나눕니다.
3. **Flow 생성**: §5 우선순위대로 생성합니다. 정상 속도 재생으로 바퀴 접지, 축 수, 그림자, 골재 꿈틀거림을 검수합니다. 실패하면 표의 대안으로 즉시 대체합니다(재생성에 매달리지 않음).
4. **CG 제작**: §3 스타일 가이드로 MOGRT 템플릿 5종(칩, 키워드, 배지, 브래킷, 노드)을 먼저 만들고 나머지를 조립합니다.
5. **검수 체크**
   - [ ] 휴대폰 가로 390px 폭에서 출처 줄(24~26px)과 배지가 읽힘
   - [ ] 비교 컷(WET, RUT)에서 디졸브·모핑·선택 확대가 0건
   - [ ] 청라 문구가 RUT·WET 이미지 위에 0건
   - [ ] 모든 Flow 클립에 글자·로고·사람 0건, 생성 오디오 제거
   - [ ] 타이틀 세이프 위반 0건(D4)
   - [ ] 마스터 −14 LUFS / TP −1.0 dBFS
