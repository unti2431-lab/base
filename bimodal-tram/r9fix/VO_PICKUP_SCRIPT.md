# VO 부분 재녹음(픽업) 원고 — 승인 전 실행 금지

조건: 원 녹음의 다른 구간, 속도, 순서는 유지합니다. 대체 문장은 원래 시간창 안에 들어가도록 음절 수를 맞췄습니다(±1음절). 시간은 원 녹음 기준이며 R9의 ASR·무음 경계에서 가져왔습니다.

| P1 | 권장 | 128.42 – 134.44초 (6.0초) · B16 둘째 문장 | 이 이론만으로 과거 청라 바이모달 트램의 운행 중단과 고장 원인을 **모두 단정할** 수는 없습니다. (38) | 이 이론만으로 과거 청라 바이모달 트램의 운행 중단이나 고장 원인을 **설명할** 수는 없습니다. (37) | "모두"가 노면 원리의 부분 책임을 함의함 |

## 녹음·편집 규칙
- TTS라면 원 녹음과 같은 음성, 속도, 스타일 설정을 씁니다. 사람 성우라면 같은 마이크, 거리, 공간으로 녹음하고, 앞뒤 문장을 이어 읽은 테이크에서 해당 문장만 잘라 씁니다(억양 연결용).
- 대체 문장의 길이가 시간창보다 길면 템포를 바꾸지 말고 다시 녹음합니다. 짧으면 문장 끝 무음으로 맞춥니다.
- 이음새마다 6~10ms 크로스페이드를 넣고, 처리 전 원본의 라우드니스 체인(−14 LUFS / TP −1.0)을 다시 적용합니다.
- 교체 뒤 G2(사실)·G4(청취) 게이트를 새 SHA256으로 다시 받습니다.
- 교체하지 않는 경우 화면 보정 문구는 `R9_RESOLUTION_PLAN.md` §5의 V5·V6 행을 씁니다.
