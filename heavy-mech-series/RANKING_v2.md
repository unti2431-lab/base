# 예비 소재 전수 평가 — 흥행성 × 제작용이성 (v2)

작성일 2026-10-25 · 대상: 이 세션의 예비 소재 13건(PLAN_v1 원안 3 + 추가 후보 9 + PAVE 제안 1)

## 0. 결론

1. **1위는 PAVE(아스팔트 피니셔 스크류)입니다.** 종합 7.58점으로, 2위 퀵커플러(7.21)와 0.37점 차이입니다.
2. PAVE가 이긴 이유는 두 가지입니다.
   - **RMC 시청층을 그대로 이어받습니다(니치밴딩).** 도로축은 업로드 이력이 없어 중복 위험도 가장 낮습니다.
   - **RMC 나선 리그를 다시 씁니다.** 그래서 제작용이성이 높습니다.
3. 약점은 위협 축이었습니다. 이번 조사로 "굵은 골재가 몰린 자리는 공극이 이어져 물·공기가 스며들고 조기 박리·포트홀로 이어진다"는 근거를 확보해 ○로 올렸습니다(Colorado DOT 분리 연구, Purdue 학위논문, 미 포장 핸드북). 수치는 쓰지 않습니다.
4. **순위가 뒤집히는 조건:**
   - 시리즈 연결 가중치를 빼면 엘리베이터가 흥행성 1위가 됩니다.
   - RMC 리그를 실제로 재사용할 수 없으면 PAVE의 제작용이성이 7.1에서 5.9로 내려가고(리그 8→5), 종합 7.10으로 퀵커플러(7.21)보다 낮아집니다.
   - 따라서 착수 전 **RMC 리그 재사용 가능 여부(G-PAVE-01)**를 먼저 확인합니다.
5. **편성 제안:** PAVE(포장) → 진동 롤러(다짐)로 "도로축 2연작"을 만듭니다. 롤러는 단독 6.50점이지만, PAVE 직후에는 시리즈 연결 점수가 올라 실질 3위권입니다.

## 1. 평가 기준

| 축 | 하위 항목(가중) | 설명 |
|---|---|---|
| 흥행성 (종합의 60%) | 훅 보편성 30% | 45~70 남성이 "그거 나도 궁금했다"고 느낄 확률 |
| | 위협 25% | 채널 3축 중 위협. 출처 있는 위협만 인정 |
| | 시리즈 연결 25% | 기존 편(포크레인 궤도, RMC) 시청층·알고리즘 이월 |
| | 중복·포화 낮음 20% | 채널 내부 중복 + 유튜브 전반 포화도(높을수록 덜 포화) |
| 제작용이성 (종합의 40%) | 리그 40% | 부품 수, 구속 난도, 기존 리그 재사용 |
| | 팩트 확보 30% | 공개 자료로 핵심 주장을 확인하기 쉬운 정도 |
| | 에셋·렌더 30% | 외관 에셋 확보, 씬 규모, 8GB VRAM 부담 |

### 2.1 2축 사분면

```
 흥행 ↑
  8 │                         ● PAVE
    │               ● 퀵커플러
  7 │  ● 타워크레인    ● 엘리베이터
    │        ● 주차타워
  6 │  ● 선로전환기          ● 롤러
    │                ● 체인블록   ● 붐대
  5 │                  ● 오실레이션   ● 지게차
    └──────────────────────────────────→ 용이
       4     5     6     7     8     9
```

- **우상단(즉시 착수):** PAVE, 퀵커플러
- **좌상단(대형 기획, 리그 투자 필요):** 엘리베이터, 타워크레인. 엘리베이터는 시리즈 연결만 약할 뿐 훅·위협이 최상이라, "안전장치 시리즈"를 따로 열면 1순위가 됩니다.
- **우하단(리그 파일럿·저비용 편):** 지게차, 붐대, 롤러, 체인블록

## 3. PAVE 제안서 검토 메모 (원안에서 바꾼 것)

| 원안 | 문제 | 반영 |
|---|---|---|
| 0–4초 "레미콘 통 속 그 나선 날개" | "레미콘", "나선 날개"가 화면에 보이기 전에 들립니다(명사 선행 노출 위반). | F1을 오거 근접(날개 + 검은 반죽)으로 열고, F37–66에 RMC 드럼 나선을 회전 위상에 맞춘 매치컷으로 1초 넣습니다. |
| 40–42초 화면 내 선택형 질문 | 루프 이음이 끊기고, 마지막 2초가 정보 없는 구간이 됩니다. | 고정 댓글 Binary CTA(1⃣/2⃣)로 옮기고 본편은 40초로 줄입니다. |
| 위협 △ "포트홀 인과는 국내 근거 따로 확보" | 위협 축 미충족 상태로 착수하게 됩니다. | 해외 공공기관·학위논문 근거로 ○ 확보(§0). 국내 근거는 G9 전까지 보강합니다(블로커 아님). |
| "좌우 날개가 서로 반대로 감김" | 좌우 구동 방향이 기종마다 다를 수 있습니다. | LOCK 기종 매뉴얼로 확인(G-PAVE-03). 미확인 시 대체 문장: "양쪽 날개는 반죽을 바깥으로 밀어내는 방향으로 감겨 있습니다." |
| 21–27초 "굵은 돌만 줄지어 남는" 가정 장면 | 완성 도로의 세로줄로 보여 주면 시공 이음과 혼동됩니다(원안 리스크 4). | 줄(선)이 아니라 **거친 질감의 띠**로 보여 주고, 매크로 비교(치밀 vs 성김)로 처리합니다. |
| 가운데 역류를 "반대 방향 입자"로 표현 | 3D 입자 효과는 씬 규범 위반 소지가 있습니다. | 입자 = 골재 인스턴스(물체)로 처리합니다. 흐름 화살표만 후합성 2.5D로 넣습니다. |
