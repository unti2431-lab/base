## 0. 결론

1. 세 소재 모두 블렌더만 할 수 있는 지점(맞물림·길이 보존·동시 구속)이 분명합니다. 다만 **G0 사실 점검에서 고쳐야 할 주장이 8건** 나왔습니다(§1). 고치지 않으면 댓글에서 "그거 기종마다 다르다"는 지적이 바로 붙습니다.
2. **제작 순서를 다시 제안합니다.** ① 퀵커플러(위협 축이 가장 강하고 레퍼런스 시청층과 직결) → ② **엘리베이터 비상정지장치(신규)** → ③ 크레인 붐대 → ④ 진동 롤러.

4. 신규 후보 6건 가운데 **엘리베이터 비상정지장치**와 **타워크레인 자가 상승(텔레스코핑)**이 기존 1순위보다 셉니다(§5).

## 3. 소재별 블렌더 구현 설계

### 3.1 크레인 다단 붐대 — 실린더 1개 + 와이어 2조

**원리 (검증 완료, `boom_rope_kin.py`)**
- 신장 와이어: S(k-1) 고정점 → **Sk 앞머리 시브**를 180° 감고 → S(k+1) 꼬리. Sk가 d만큼 나오면 S(k+1) 꼬리는 월드에서 2d를 움직입니다. 즉 Sk 위에서 d만큼 더 미끄러집니다.
- 회수 와이어: S(k+1) 꼬리 → **Sk 후단 시브** → S(k-1) 앞쪽 고정점. 같은 1:2 관계를 반대 방향에서 묶습니다.
- 두 와이어가 앞뒤에서 묶기 때문에 실린더가 밀 때도, 당길 때도 각 단이 따로 놀지 않습니다. 이것이 대본의 결말 문장입니다.
- 검증 결과: 와이어 4가닥의 길이 편차는 0.000 mm(해석해)입니다. 월드 변위비는 S2:S3:S4 = 1:2:3이고, 스트로크 1 m에 시브(r = 0.09 m)는 1.77바퀴 돕니다.

**원안 팁에 대한 수정**

| 원안 | 문제 | 대안 |
|---|---|---|
| Transformation 컨스트레인트로 월드 +1/+2/+3 m 매핑 | 붐이 기복(위로 들림)하면 월드 축 매핑이 깨집니다. | **부모 체인**: S2 → S1, S3 → S2, S4 → S3로 부모를 걸고, 각 단의 로컬 x = d를 같은 값으로 베이크합니다. 월드 1:2:3이 자동으로 나오고, 붐 기복과도 무관합니다. 키는 d(t) 하나입니다. |
| Bezier + Hook으로 와이어를 시브 중심에 묶기 | 와이어가 시브 원주가 아니라 **중심을 지나갑니다**(관통). | 와이어 = 직선 2구간 + 시브 반원(πr)을 해석적으로 배치하고, Geometry Nodes Curve to Mesh로 두께를 줍니다. 또는 접점 2개를 Hook으로 걸고 반원 구간은 시브 자식 커브로 둡니다. |
| 와이어 움직임 | 매끈한 원통은 움직여도 움직이는 것처럼 보이지 않습니다. | 와이어에 **0.5 m 간격 표식**(드물게)을 두고, UV를 와이어 상대속도로 흘립니다. 그래야 "2배로 끌려간다"가 눈에 보입니다. 촘촘한 줄무늬는 모아레 위험이 있어 쓰지 않습니다. |

**모델링 범위**: 사각 파이프 4단(속 빈 단면, 벽두께 표시), 슬라이드 패드(단 사이 간극 1–2 mm), 실린더(튜브 + 로드), 시브 4개, 와이어 4가닥, 고정 클레비스. 외관용 트럭은 구매/CC0 에셋.

**QC 추가 항목**: 와이어 길이 보존 < 0.5 mm, 시브 무미끄럼(와이어 UV 속도 = ωr), 단 간 최소 겹침 길이, BVH 충돌(단-단, 와이어-파이프 내벽, 와이어-시브 홈).

**비교 컷("와이어가 없다면")**: 같은 베이크에서 S3·S4 로컬 x = 0으로 둔 변형본을 씁니다. 빨강 후합성은 이 컷에만 씁니다.

**위협 축 보강(게이트 리스크)**: 원안에는 위협 요소가 없습니다. LOCK한 기종의 최대 작업 높이·정격 하중(제조사 수치)으로 규모감을 주는 정도가 안전합니다. "따로 놀면 이음부가 꺾인다" 같은 주장은 출처가 없으면 쓰지 않습니다.

### 3.2 포크레인 퀵커플러 — 앞 핀 안전 걸쇠

**리그 구성**: 커플러 본체(암 링크에 고정) / 앞 턱(고정 후크) / 뒤 가동 후크(실린더 슬라이드) / **안전 걸쇠**(피벗 + 리턴 스프링) / 바가지(앞 핀·뒤 핀, 핀 간격 LOCK).

**운동 시퀀스(해석적 베이크)**
1. 체결: 앞 핀이 앞 턱으로 들어갈 때 걸쇠의 경사면이 핀에 밀려 열립니다. 걸쇠 각도는 핀 중심 위치의 함수로, 접촉 조건 `|핀중심 − 걸쇠 경사면| = r_pin + 1 mm`에서 풉니다. 핀이 지나가면 걸쇠는 스프링으로 닫힙니다(사건 F 기록 → 딸깍 SFX).
2. 크라우드: 바가지가 앞 핀을 축으로 돌아 뒤 핀이 안착합니다.
3. 잠금: 실린더가 뻗어 뒤 후크가 뒤 핀을 뭅니다(주황 압력 후합성).
4. 실패 가정: 압력이 0이 되고 뒤 후크가 풀립니다. 바가지는 앞 핀을 축으로 회전하며 아래로 쏠리고, 앞 핀은 걸쇠의 닫힌 턱에 걸려 멈춥니다.
5. (확인된 경우만) 해제: 지정 자세에서만 걸쇠가 열립니다.

**핵심 QC**: 실패 구간 전체에서 "걸쇠를 닫는 방향의 모멘트 > 0"을 베이크에서 계산해 기록합니다(핀 반력 벡터 × 걸쇠 피벗 거리). 이 값이 음수가 되는 프레임이 있으면 형상이 틀린 것입니다. 이 반력 벡터는 후합성 화살표로도 그대로 씁니다.

**맞물림 정밀도**: 턱 안쪽은 반경 r_pin + 1 mm 원호로 만들고, 핀과의 접촉은 1 mm 이하 설계 접촉 목록으로 분류합니다.

### 3.3 진동 롤러 — 회전 방향으로 바뀌는 진폭

**원리(LOCK)**: 편심축에 고정추 1개, 자유추 1개(축 위에서 자유 회전, 멈춤턱 2개 사이 180° 범위)를 둡니다.
- 정회전: 자유추가 고정추와 같은 쪽 턱에 걸립니다 → 편심 모멘트 합 = m1r1 + m2r2(고진폭).
- 역회전: 축이 반대로 돌기 시작하면 자유추는 관성으로 제자리에 남습니다. 축이 반 바퀴 돌아 반대편 턱이 자유추를 낚아챕니다 → m1r1 − m2r2(저진폭).
- 이 "반 바퀴 넘어감"이 머니샷입니다. 해석적으로는 축 감속 → 0 → 역가속 구간에서 자유추 월드 각을 고정하고, 상대각이 180°에 도달하면 다시 축에 묶습니다.

**구현 주의**
- 실제 회전수(제조사 진동수 Hz)를 30fps로 렌더하면 프레임당 수백 도가 돌아 바퀴가 거꾸로 도는 듯 보입니다(왜건휠 현상). **슬로모션 배율을 LOCK**하고 자막으로 "실제 속도의 1/○○"를 고지합니다.
- 진동은 Noise 모디파이어로 흔들지 않습니다. 드럼 수직 변위 = A·sin(θ_shaft)로 베이크하고, A는 편심 모멘트 합에 비례시킵니다(고/저 대비가 숫자로 맞아야 합니다).
- 드럼 구름: 무미끄럼 θ_drum = x/R. 편심축 회전과 드럼 구름은 서로 별개 축입니다(원안의 '이중 회전축 분리').
- 땅 울림은 3D 입자가 아니라 후합성 동심원 링(도형)으로 넣습니다.
- 차체-드럼 사이 방진고무는 한 컷 디테일로만 둡니다(One Big Idea 유지, 출처 확인 후).

### 3.4 엘리베이터 비상정지장치 (신규 추천 1위, §5)

**리그**: 카 프레임, 가이드 레일 2개, 조속기(시브 + 플라이웨이트 2개 + 스프링 + 래칫), 조속기 로프 루프(상단 조속기 ↔ 피트 인장 시브), 카 하부 세이프티 링크, 쐐기 2쌍(테이퍼 하우징).

**운동 시퀀스**
1. 정상: 카 속도 v → 조속기 시브 ω = v/r. 플라이웨이트 전개각은 원심력과 스프링력의 평형각으로 계산합니다(해석식).
2. 과속: 전개각이 임계값에 닿으면 웨이트 끝이 래칫을 찹니다 → 조속기 시브 정지 → 조속기 로프 정지.
3. 카는 계속 내려가고 로프는 멈췄으니, 카 기준으로 로프가 상대적으로 위로 움직입니다 → 세이프티 링크가 회전 → 쐐기가 테이퍼 안으로 끌려 올라갑니다.
4. 쐐기가 레일을 양쪽에서 물고, 카가 감속·정지합니다(감속 곡선은 단순 등감속, 수치는 기준서 확인 후).

블렌더만 할 수 있는 지점: 원심 전개 → 래칫 걸림 → 로프 상대운동 → 링크 → 쐐기 테이퍼 파고듦으로 이어지는 5단 연쇄 구속입니다.

사실 확인 필요: 작동 속도 기준(정격 대비 %)은 한국 승강기 안전기준(행정안전부 고시) 원문으로 확인합니다. 블로그의 "115%"는 근거가 확인되지 않았습니다. 기계실 없는(MRL) 기종은 조속기 위치가 다릅니다. 대본은 "로프는 여러 가닥이고 브레이크도 따로 있다"는 사실을 해치지 않게, "설령 끊어지더라도"로 씁니다.
